# 任务图执行器（taskgraph-executor）

冻结任务图的执行协议：逐节点派子 Agent、交独立协查验证、主 Agent 只裁报告并按分支分流，带预算封顶与决策门，完成输出终报。

## 结构

- `SKILL.md` — 技能入口
- `references/` — 参考文档

## 安装

- **通用 Agent Skill 平台（Claude / CodeBuddy / Cursor 等）**：将本目录放入平台的 skills 目录即可
- **TeleAgent / Octop**：导入本技能包后启用
